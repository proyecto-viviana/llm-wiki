# Question: when to require pins

- **Status:** open
- **Stop condition:** The instance schema states, in one table, which stakes
  require which minimum evidence level — and a reviewer can check a page against
  it without asking the author.
- **Notes:** The pattern recommends L2 for load-bearing claims. Each instance
  chooses thresholds; the provenance gate then decides whether a given source is
  even eligible for that level.
