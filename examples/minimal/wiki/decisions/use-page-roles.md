# Decision: use page roles

## Question

Should every wiki page be the same kind of object?

## Stop condition

A minimal role set that supports ingest multi-page updates and closed judgment.

## Disposition

**Yes.** Distinguish at least: source page, concept/entity hub, decision, open
question, query residue.

## Evidence level

L1 synthesis over own-corpus notes. The example's single L2 pin
(`CLAIM-normative-keywords`) backs a wording question, not this decision — a
decision may rest at L1 as long as it says so.

## Non-claims

- Does not mandate a folder taxonomy beyond the template defaults.
- Does not require L2 for personal journals.
- Does not claim the role set is complete; it is a floor, not a ceiling.
