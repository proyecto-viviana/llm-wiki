# Decision: prefer multi-page ingest

## Question

Is a source page alone a complete ingest?

## Stop condition

A clear rule an agent can follow without Strict claim packets.

## Disposition

**No.** Every ingest must update (or create) relevant hubs, plus index and log.
Leaf-only ingest is incomplete.

## Evidence level

L1 synthesis over teaching sources and own notes.

## Non-claims

- Does not require L2 claim JSON for ordinary ingests.
- Does not ban small personal journals from using fewer hubs when scope is tiny.
- Does not choose a specific search engine.
