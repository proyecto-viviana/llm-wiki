# Concept: associative trails

Recorded connections between items so a path of interest can be re-followed.

## Current synthesis

- Origin metaphor: Memex ([sources/bush-memex.md](../sources/bush-memex.md)).

- Search can *find* pages; trails are *authored maintenance* on hubs.
