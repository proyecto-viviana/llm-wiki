# Query residue: compile vs search

**Asked:** How do compiled wikis relate to local markdown search?  
**Filed:** 2026-07-30

## Answer

They stack. The wiki **compiles** knowledge into hubs and decisions so synthesis
is maintained. Local search **retrieves** pages when the index is too large to
read whole. Search without compile reverts toward RAG-over-files; compile without
any retrieval still works at small scale via index-first navigation.
